
# Clothing Demand Predictor

## Project Description
The Clothing Demand Predictor estimates the number of clothing
units that may be sold using Multiple Linear Regression.

## Features
1. Price
2. Discount Percentage
3. Previous Sales
4. Advertising Spend
5. Seasonal Demand Index

## Target
Units Sold

## Algorithm
Multiple Linear Regression

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Flask
- HTML, CSS and JavaScript

## Dataset
The project uses 500 synthetic sample records for educational
purposes.

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Execution
1. Install requirements.
2. Run train_model.py.
3. Run app.py.
4. Open http://127.0.0.1:5000/ in a browser.

## Expected Output
The website displays the estimated number of clothing units
that may be sold for the given input values.
